Morse Code Practical
-Morse code is an alphabet or code in which letters are represented by combinations of long and short lines or sound signals.
-Morse code started because of the electrical telegraph system that was invented by a man called Samual F.B. Morse, Joseph Henry and Alfred Vail. This telegraph sent messages over long distances by using pulses of electricity to signal a machine to make marks on paper. However, these messages were only useful if it is understandable so they created morse code and assigned each letter to the code.
